# AE2 Utilix

## Overview

AE2 Utilix adds some small utilities and modifies certain mechanics.

## Additions

- **Product Return Card** – Allows the ME Interface to extract products from the same face after pushing materials.
- **Phase Card** – Changes the direction in which the ME Interface sends materials.
- **Parallel Card** – Increases the number of parallel operations for a device (currently only supports the Crystal Growth Chamber).
- **Crystal Growth Chamber** – Provided for pack developers. By default, it can only produce Fluix Crystals. Supports recipe modification via CraftTweaker.
- **Phase ME Interface** – Can bind to a machine/container within 16 blocks (wireless).
- **Matter Decomposer** – A new tool with three modes:
  - Matter Dissolver Mode
  - Brittle Material Analysis Mode
  - Regular Material Processing Mode
- **Coupling Staff** – Used to bind the Phase ME Interface. If used to attack an entity, it deals 30 points of damage that ignores armor and damage reduction.
- **Four block‑form terminals** – Similar to Fullblock Energistics.
- **Block Storage Bus** – Can read blocks, item entities, and containers, and can also write to item entities and containers.

## Changes

- The **Magnet Card** can now be placed into the ME Interface to collect nearby item entities (configurable on/off).
- CPU usage can now be restricted to either players or automation systems (configurable on/off).
